📋 How to Connect Any Google Sheet (2 Minutes):

  1. Create Google Form: Create your registration form & open its linked Google Sheet.
  2. Open Script Editor: Inside the Google Sheet, click Extensions > Apps Script.
  3. Paste Backend Code: Delete existing code, paste the contents of GoogleAppsScript_Backend.gs from this project, and click Save (💾).
  4. Deploy as Web App: Click Deploy > New deployment > select type Web app:
    • Execute as: Me
    • Who has access: Anyone (critical for scanner API requests!)
  5. Copy Web App URL: Copy the URL ending in /exec and paste it into the Google Sheet Web App URL field in Tab 2 or Tab 1.
